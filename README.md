# デジタル学習指導要領

小学校学習指導要領を、引く・くらべる・たどるためのページです。

- 入口：`docs/index.html`（教科ごとのリンク集）
- 国語：`docs/kokugo/index.html`（指導事項・系統・前回とくらべる・歩み）
- 特別活動：`docs/tokkatsu/index.html`
  - いまの本文（平成29年告示）／前回（平成20年告示）とくらべる／歩み（図あり）／次の改訂／用語

## 作り直し方（特別活動）

```
python3 tools/build_tokkatsu.py
```

- `data/国のコード表_小学校_82V12.csv`：いまの本文（文部科学省「学習指導要領コード」）
- `data/tokkatsu_h20.json`：前回の本文（国立教育政策研究所「学習指導要領データベース」）
- `data/tokkatsu_extra.json`：くらべの対応・用語・歩み・次の改訂（手で書く所）
- `mock/template_tokkatsu.html`：画面のひな形

「次の改訂」は 2026年11月3日に たしかめた内容です。答申・告示が出たら `tokkatsu_extra.json` の `next` を直します。
